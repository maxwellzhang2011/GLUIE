# GLUIE

**A simple, GPU-accelerated 2D graphics library written in Rust.**

## Why did I make this?

Getting started with graphics programming can be challenging. You often have to learn low-level graphics APIs and work with additional libraries to implement features like text rendering.

I created GLUIE to make low-level graphics development easier and more approachable while keeping it fast and lightweight.

My goal is to make graphics programming simpler without sacrificing performance or flexibility.

## Features

- GPU-accelerated 2D rendering using OpenGL.
- Rectangle and image rendering.
- An API designed to make graphics programming easier.
- Text rendering and other features are under development.
